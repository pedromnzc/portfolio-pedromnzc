# Pessoa Engenheira de Software Júnior (Back-end)

> Vaga fictícia, criada para testar o revisor do portfólio.

- **Empresa:** Cerrado Sistemas (software de gestão para cooperativas)
- **Local:** Remoto, com encontros mensais em Brasília, DF
- **Regime:** CLT
- **Salário:** R$ 5.500,00 + benefícios

## Sobre a vaga

Nosso produto é usado por mais de 200 cooperativas. Procuramos uma pessoa para o time
de back-end, que mantém as APIs, a integração com sistemas bancários e os serviços de
emissão de notas.

## Atividades

- Desenvolver e manter APIs REST.
- Escrever testes automatizados (unitários e de integração).
- Participar de revisões de código e de cerimônias ágeis (Scrum).
- Modelar bancos de dados relacionais e otimizar consultas.
- Acompanhar deploys e monitorar serviços em produção.

## Requisitos obrigatórios

- Graduação completa ou em andamento em Computação, Engenharia de Software ou afins.
- Pelo menos 1 ano de experiência com desenvolvimento back-end.
- Domínio de Java (Spring Boot) **ou** Python (FastAPI ou Django).
- APIs REST, autenticação (OAuth 2.0, JWT) e boas práticas de segurança.
- SQL e um banco relacional (PostgreSQL ou MySQL).
- Testes automatizados.
- Git e fluxo de pull requests.

## Diferenciais

- Docker e CI/CD (GitHub Actions ou GitLab CI).
- Nuvem (AWS ou GCP).
- Mensageria (RabbitMQ ou Kafka).
- Experiência com sistemas financeiros.
