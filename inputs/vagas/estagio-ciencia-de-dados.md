# Estágio em Ciência de Dados

> Vaga fictícia, criada para testar o revisor do portfólio.

- **Empresa:** Trilho Analytics (consultoria de dados para mobilidade e logística)
- **Local:** Brasília, DF, híbrido (3 dias no escritório)
- **Carga horária:** 30 horas semanais
- **Bolsa:** R$ 2.200,00 + vale-transporte

## Sobre a vaga

Buscamos estudante para o time de Ciência de Dados, que apoia órgãos públicos e
empresas de transporte a tomar decisões com dados. Você vai participar de projetos de
previsão de demanda, análise de reclamações de usuários e painéis de indicadores.

## Atividades

- Coletar, limpar e organizar bases de dados de diferentes fontes.
- Construir análises exploratórias e relatórios reprodutíveis.
- Treinar e avaliar modelos de aprendizado de máquina (classificação e regressão).
- Aplicar técnicas de Processamento de Linguagem Natural em textos de atendimento.
- Montar painéis de acompanhamento para os clientes.
- Documentar o código e apresentar resultados para pessoas não técnicas.

## Requisitos obrigatórios

- Cursando graduação em Ciência de Dados, Estatística, Computação ou áreas afins,
  a partir do 4º semestre.
- Python para análise de dados (pandas, NumPy).
- SQL para consultas e junções.
- Noções de estatística e de aprendizado de máquina (scikit-learn).
- Git para versionamento.

## Diferenciais

- Experiência com NLP (spaCy, Transformers).
- Conhecimento de LGPD e anonimização de dados.
- Power BI ou outra ferramenta de visualização.
- Docker.
- Experiência prévia no setor público ou em transporte.
